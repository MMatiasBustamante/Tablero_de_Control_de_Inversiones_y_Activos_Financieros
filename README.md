# Proyecto-Tablero-de-Control-de-Inversiones-y-Activos-Financieros
Primer proyecto autodidacta en análisis de datos.
> Proyecto de análisis de datos para portfolio personal. Integra Python, SQL, Google Sheets y Power BI para construir un dashboard interactivo de seguimiento de inversiones.

---

## 🗂️ Estructura del proyecto

```
├── data/               # Datos crudos y procesados (.csv)
├── notebooks/          # Jupyter Notebooks (ETL y EDA)
├── sql/                # Schema y queries analíticas
├── powerbi/            # Archivo .pbix del dashboard
├── img/                # Capturas del dashboard
└── README.md
```

---

## 🛠️ Stack utilizado

| Herramienta | Uso |
|---|---|
| Python (Pandas, NumPy) | Extracción, limpieza y métricas de riesgo |
| SQL (SQLite) | Almacenamiento y consultas analíticas |
| Google Sheets | Hoja de portafolio y análisis exploratorio |
| Power BI | Dashboard interactivo final |
